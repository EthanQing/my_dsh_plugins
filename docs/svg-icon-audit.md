## 状态覆盖

Git 实际组件覆盖干净、未暂存、已暂存、混合改动、待推送、读取中、操作中、读取失败、已有状态后失败、非仓库、游离 HEAD 和冲突。宽栏与窄栏都用 SVG，窄栏保留主要状态；游离 HEAD 使用提交节点图标，与非仓库的文件夹斜杠区分。文件新增/修改/删除/重命名/复制/类型变更/冲突等徽标也不再使用字母代替图形。

子代理实时事件与旧格式输出均使用结构化 `{icon,text}`，由渲染器绘制 SVG，不再先拼接字符图标；用户输出中原有的 emoji、Markdown 和代码保持原样。中英文界面文案移除图标字符，图标按钮保留可访问名称，加载动画支持减少动态效果偏好。

## 验证

- Git 状态与交互测试：27 项通过；真实组件隔离浏览器检查覆盖 12 种状态、24 个宽窄入口，验证 SVG、无状态文字、22px 高度和不换行。
- 同栏布局与宿主所有权测试：8 项通过，含 41 项浏览器断言；居中三项信息、右侧工具、宽窄切换、弹层边界和卸载恢复通过。布局 fixture 已改为实际 Git 组件，不再用字符状态的假图。
- 子代理图标回归测试：6 项通过，覆盖按钮待处理状态、事件和旧格式输出、用户 emoji 保留、统计数值与 tooltip 一致，以及完整浏览器 factory 编译。
- Git、子代理侧栏和终端的源码/运行产物一致性检查通过。两个手写客户端通过语法检查。Markdown 和 Codex 的旧产物与当前构建器有排版差异；仅规范化 JavaScript 排版后输出一致，保留原产物，不引入无关格式修改。智能标题按现有脚本同步运行文件。
- 运行 `npm run check:icons` 可复查全部 9 个插件的自有源文件、语言资源、预设及 SVG。该检查解码常见 Unicode/CSS/HTML 转义，发现已知图标字符时失败；它辅助人工审计，不能替代对任意字符串语义的判断。此命令在源码仓库运行。

## 范围

终端供应商代码中的字符集、终端输出、用户输入以及测试用用户内容不属于插件图标。重命名关系的“旧路径 → 新路径”是文件元数据；增删行的正负号是数学数据。这些内容不转换成图标。

截图和浏览器检查来自隔离渲染，不代表已安装到运行中的 Desktop。未安装依赖、启用插件、修改 Profile 或重启 DSH。
